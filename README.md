# Могоби

Восстановление русской версии Mogobe на оригинальных SWF. Клиент для Windows использует Go, Wails, WebView2 и Ruffle; новый сервер — FastAPI и SQLite.

Работают регистрация, сохранённая авторизация, выбор могоби, карта и 50 локаций, совместная игра, чат, профили, друзья, личный мут, эмоции и магия. Обычный вход начинается в Новограде; F5 переподключает в текущую комнату. Магазины дают опыт за покупки. Полный справочник — на странице [чат-команд](docs/chat-commands.md). Единая админка сервера запускается отдельно через `StartAdmin.bat`.

Работают настраиваемые магазины с покупками и инвентарём. Одежда надевается из оригинального профиля и видна другим игрокам, включая движение; выбор сохраняется после входа. Фотоаппарат в своём профиле копирует изображение могоби с одеждой в буфер обмена Windows. Подключена оригинальная рыбалка: вход в Севербурге или `/game goldfishing`, монеты и опыт за набранные очки, включая досрочный выход. Исторический ассортимент, остальные миниигры, личные дома, почта и восстановление пароля пока не подключены. Часть маршрутов между комнатами ещё не определена. Это новый клиент и сервер для найденных ресурсов, а не исходный сервер закрытой игры.

## Быстрый запуск на Windows

Нужны Python 3.12+, [uv](https://docs.astral.sh/uv/getting-started/installation/), Go 1.25+ и [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

1. Соберите клиент из корня репозитория:

   ```powershell
   python tools\build_client.py
   ```

2. Запустите `StartServer.bat`: он установит зависимости, создаст SQLite и применит миграции. Оставьте окно открытым.
3. Запустите `StartClient.bat`: можно создать могоби через оригинальную регистрацию или войти как `admin` с паролем `admin`.

Готовый клиент находится в `dist/Mogobe/`. Для его запуска Python и Go не нужны; нужен WebView2 Runtime. Сборки и локальная база в Git не включаются.

## Подключение

По умолчанию клиент подключается к `http://localhost:8000`. Для своего сервера измените `client.json` рядом с EXE:

```json
{
  "server_url": "https://mogobe.example.com",
  "request_timeout_seconds": 15
}
```

Адрес можно передать аргументом: `Mogobe.exe --server https://mogobe.example.com`. Сервер запускается отдельно от клиента.

## Чат-команды

В игре отправьте `/help`, чтобы открыть справку с учётом своих прав. Полный [справочник чат-команд](docs/chat-commands.md) содержит синтаксис, примеры, ключи магазинов, выдачу вещей, опыта и монет, объявления и ограничения.

Клавиша **F5** переподключает в текущую локацию. `/exit` возвращает к выбору могоби; следующий обычный вход начинается в Новограде.

## Магазины в локациях

Магазины открываются одним окном после подхода персонажа к исходной торговой точке и получения каталога. Покупка сохраняет текущую категорию и страницу.

Подключены 14 магазинов, включая Вьюгово и магазины бумаг. Все названия и ключи для `/shop` перечислены в [справочнике](docs/chat-commands.md#открытие-магазинов).

В отдельной админке выберите магазин и задайте «Точки в локациях». Можно привязать несколько точек к одному магазину или переназначить точку другому; изменения действуют без перезапуска. Здесь же меняются доступ, категории, товары, цены, опыт и остатки.

При первом запуске создаются 14 открытых магазинов со стартовыми подборками. Это приблизительное восстановление по графике и иллюстрациям вики: точные исторические ID и цены не подтверждены. Начальные цена и опыт — по 10; их можно менять. Повторный запуск сохраняет ваши изменения и удалённые предложения. Источники и подборки — [world-shops.json](assets/catalogs/world-shops.json).

Категория инвентаря задаётся у самого предмета. У категории магазина можно дополнительно указать общий слот: сохранение категории или перенос в неё предложения применяет слот к этим вещам у всех владельцев. Пустое поле сохраняет индивидуальные слоты. Купленные вещи, монеты, опыт и экипировка сохраняются в SQLite. Открытый инвентарь обновляется сразу. Надетая вещь переезжает в свободный слот; при конфликте снимается, оставаясь в собственности.

## Права администратора и админка

При запуске сервера автоматически создаются могоби **`admin` / `admin`** с правами администратора и три закрытых магазина со всеми 2 456 найденными ID: **`/shop admin1`** (одежда и украшения), **`/shop admin2`** (бумаги), **`/shop admin3`** (интерьер дома). Этим аккаунтом можно войти и в игру, и в общую админку через `StartAdmin.bat`. Если аккаунт `admin` уже существует, его пароль, регистр имени и права сохраняются. Существующие настройки товаров также сохраняются.

Чтобы выдать права другому существующему игровому аккаунту:

1. Запустите `StartServer.bat`, чтобы применились миграции, и создайте могоби через регистрацию в клиенте.
2. На машине сервера откройте PowerShell в корне репозитория и выполните, заменив `YOUR_USERNAME` на ник своего могоби:

   ```powershell
   cd .\server
   uv run python -m src.admin grant YOUR_USERNAME
   cd ..
   ```

   Команда использует настройки БД этого сервера, включая `server/.env` и переменные окружения.

3. Запустите `StartAdmin.bat` из корня репозитория или откройте [админку](http://localhost:8000/admin). Войдите по нику и паролю того же игрового аккаунта.

В общей админке доступны обзор сервера, могоби и назначение прав, балансы, предметы и магазины. Во вкладке «Могоби» можно назначать и снимать права других аккаунтов без перезапуска сервера. Через панель нельзя снять права у последнего администратора.

Чтобы снять права через консоль, из корня репозитория выполните:

```powershell
cd .\server
uv run python -m src.admin revoke YOUR_USERNAME
cd ..
```

Административные магазины заполняются при запуске сервера:

- `/shop admin1` — одежда и украшения, с категориями по слотам. Оригинальная примерка на персонаже, покупка и надевание из инвентаря работают как в обычном магазине одежды.
- `/shop admin2` — бумаги, корм, игрушки и зелья.
- `/shop admin3` — мебель и декор; отдельные категории для транспорта и пазлов.

Обновить каталоги можно кнопкой «Обновить три админ-магазина» во вкладке «Магазины» или из папки `server/`:

```powershell
uv run python -m src.shops.seed_admin
```

Новые предложения бесплатны, без начисления опыта и ограничения остатка. Старые числовые категории автоматически распределяются между тремя магазинами с сохранением цен, остатков и покупок. Ручные описания и настройки сохраняются. Типы восстановлены по оригинальной графике; слоты части одежды определены по расположению изображения и могут потребовать уточнения в админке. У 108 ID сохранилась только анимация Walking: они находятся в категории «Неполные анимации» и пока не надеваются. Бумаги и интерьер покупаются и сохраняются как отдельные типы; прогулки с питомцами, обустройство дома и транспорт ещё не реализованы.

Для подключения админки к удалённому серверу:

```powershell
.\StartAdmin.bat https://mogobe.example.com
```

Выдачу и снятие прав через CLI выполняйте на самом сервере. Старый `StartShopAdmin.bat` также открывает единую админку.
