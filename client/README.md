# Windows-клиент

[Назад к проекту](../README.md)

Go-оболочка Wails запускает оригинальные SWF через встроенный Ruffle в WebView2. Сервер FastAPI работает отдельно. Flash Player и браузерный плагин Adobe не требуются.

## Сборка и запуск

На Windows нужны Go 1.25+, Python 3.12+ и WebView2 Runtime. Из корня репозитория:

```powershell
python tools\build_client.py
.\StartClient.bat
```

Скрипт подготавливает ресурсы из `assets/`, собирает EXE и создаёт `dist/Mogobe/`. Wails закреплён в `go.mod`; Node.js, Java и JPEXS для обычной сборки не нужны. Готовый клиент требует только WebView2 Runtime. Оригиналы, адаптер, Ruffle и графика всех 2 456 предметов встроены в EXE. Изображения магазина и инвентаря, примерка и обе анимации одежды читаются локально; внешние папки ресурсов и архив игры не требуются. Сервер передаёт ID, цены, категории, остатки, владение и экипировку.

Сборка со всей графикой предметов занимает около 154,5 МБ (147,4 МиБ); дополнительный пакет ресурсов рядом с EXE не нужен.

Если старый EXE открыт и Windows запрещает замену, новая сборка сохраняется как `Mogobe-update.exe` рядом с ним. Настройки подключения при сборке не сбрасываются.

## Подключение

Рядом с EXE лежит `client.json`:

```json
{
  "server_url": "http://localhost:8000",
  "request_timeout_seconds": 15
}
```

```powershell
.\Mogobe.exe --server https://mogobe.example.com
.\Mogobe.exe --config C:\Mogobe\client.local.json
```

Приоритет: `--server` → файл `--config` или `client.json` рядом с EXE → localhost. Поддерживаются HTTPS и адреса с префиксом пути. Шаблон удалённого подключения — `client.remote.example.json`. Из корня можно использовать `StartRemoteClient.bat https://mogobe.example.com`; без аргумента он читает `MOGOBE_SERVER_URL`.

Для каждого сервера и одновременно открытого окна используется отдельный профиль WebView2. Игровой TCP-поток SWF проходит через локальный WebSocket Go-шлюза на `/legacy/socket` сервера. Дополнительный открытый порт 9339 на сервере не нужен.

## Управление и авторизация

Чат принимает сообщения от одного до 240 символов; пустая строка не отправляется. Кнопка со стрелкой над полем ввода раскрывает оригинальную панель истории из израильского интерфейса. Панель расположена по центру и соединена с нижней игровой панелью, с исходным полупрозрачным фоном. Строки учитывают сужение книзу, ники выделены цветом, между сообщениями нет пустых строк. При раскрытии верхняя кнопка сменяется нижней кнопкой сворачивания у края окна; она слегка перекрывает верх поля ввода. Перед ником отображается местное время получения сообщения в формате `[ЧЧ:ММ]`, сохранённое при F5. В ней хранятся последние 200 полученных сообщений с никами, включая готовые фразы. Прокрутка — колёсиком мыши; новые сообщения не сбрасывают позицию при чтении старых. История сохраняется при переходах и F5, очищается при `/exit` и закрытии приложения и не записывается в базу или на диск. Мут применяется сервером до доставки сообщения.

Полный список игровых команд и примеры — в [справочнике чат-команд](../docs/chat-commands.md).

| Действие | Результат |
| --- | --- |
| Клик по земле | Оригинальные поиск пути и анимация ходьбы |
| Карта или проход | Переход в доступную комнату |
| `/exit` | Возврат к выбору могоби с сохранением авторизации |
| `/shop <key>` | Оригинальное окно магазина; отдельные магазины доступны только администраторам |
| `/help` | Панель доступных команд с учётом текущих прав |
| `/alert текст` | Объявление всем игрокам во всех локациях (администратор) |
| `/online` | Число игроков, видимое только отправителю |
| `/room Novograd` | Просмотр комнаты по имени SWF или русскому названию |
| F5 в мире | Переподключение в текущую комнату |

Обычный вход начинается в Новограде. Появление случайное; после прохода — возле входа в новую комнату. Оригинальная заставка остаётся до загрузки комнаты, панели и персонажа.

«Запомнить имя» добавляет могоби в оригинальный список, «Запомнить пароль» сохраняет сессию без хранения пароля. В списке до шести могоби, по четыре на странице. Кнопка «Выйти» на экране выбора удаляет выбранную запись и отзывает её сохранённую сессию при доступном сервере.

Данные находятся в `%LOCALAPPDATA%\Mogobe\accounts-<server-hash>.dat`; дополнительные окна получают отдельные файлы. Токены зашифрованы Windows DPAPI для текущего пользователя и не передаются в JavaScript или Flash. Недоступность сервера не очищает список.

На экране авторизации большой портрет и маленькие карточки показывают надетую одежду через оригинальный `LoginAvatar`. Для каждого сохранённого могоби локально хранится снимок ID экипировки; он обновляется при серверных событиях входа, надевания и снятия вещей и сохраняется даже при запоминании только имени. При открытии авторизации доступная сессия позволяет однократно освежить внешний вид с сервера. Ошибка связи или истёкшая сессия сохраняет последний снимок. Эти данные используются только для портретов: владение и экипировку в игре определяет сервер.

## Разработка

| Путь | Назначение |
| --- | --- |
| `main.go`, `profiles_windows.go` | Окно, ресурсы и изолированные профили |
| `internal/config/` | Загрузка и проверка подключения |
| `internal/accounts/` | Список могоби и DPAPI |
| `internal/gateway/` | REST, старые запросы SWF и игровой WebSocket |
| `frontend/*.js`, `*.css`, `index.html` | Код запуска и адаптации интерфейса |
| `../tools/host/MogobeHost.as` | Загрузка оригиналов и исправления их поведения |

Копии ресурсов и страницы регистрации в `frontend/` генерируются. `tools/prepare_item_assets.py`, вызываемый общей подготовкой, создаёт 2 456 совместимых миниатюр, копирует 1 838 объединённых анимаций и готовит 7 шаблонов иконок (около 94 МБ). Исходные `InUse` и `Walking` не дублируются в EXE. Изменения ассортимента, цен и категорий не требуют пересборки; для добавления новой графики обновите `assets/` и пересоберите клиент. Правьте оригинальные страницы в `assets/original/registration-pages/`, поведение — в нашем JS или SWF-адаптере.

Из этой папки на Windows: `go test ./...`. Нативные проверки окна и пересборка адаптера описаны в [инструментах](../tools/README.md).

Админка запускается отдельно через `StartAdmin.bat`; в игровой клиент она не встроена. Права проверяет сервер. Изменения открытого магазина доставляются игровыми событиями без перезапуска и фонового опроса каталога. Цена повторно проверяется при покупке; если она изменилась, требуется заново выбрать товар. Купленные вещи сохраняются в инвентаре, за покупку начисляется настроенный сервером опыт с оригинальным попапом. Подсказка профиля показывает «Уровень: N». Администратор может выдать себе или другому могоби вещь, опыт и монеты командами `/give item ID [ник]`, `/give exp ЧИСЛО [ник]` и `/give coins ЧИСЛО [ник]`; его золотой значок могокарты обновляется при изменении прав. Расстановка мебели пока не реализована.

Одежда надевается щелчком по вещи в оригинальном инвентаре профиля. Щелчок по надетой вещи на большом могоби снимает её. Изменения сразу видят игроки в комнате; одежда сохраняется при переходах, F5 и повторном входе. Кнопка фотоаппарата копирует портрет с одеждой в буфер обмена Windows — его можно вставить в графический редактор или мессенджер. Изображение обрабатывается локально, без загрузки на игровой сервер.

В командах `/give` ник необязателен: без него вещь, опыт или монеты выдаются себе, с ним — указанному могоби. Получатель может находиться вне сети. `/help` использует оригинальную рамку и шрифт; `/alert` показывает сообщение каждому подключённому игроку.

Адаптер использует штатное завершение ходьбы и точный контур исходного триггера для открытия назначенного сервером магазина; клики по произвольным областям не перехватываются. Привязки загружаются при входе в комнату и обновляются событиями редактирования. Запросы оригинального SWF к `/Swf/Items/Display`, `/InUse` и `/Cats` Go-шлюз обслуживает из встроенного пакета `frontend/items/`, без запросов к серверу. Пропущенный ID возвращает локальный 404. Категории, добавленные через админку, используют локальные иконки: шлюз создаёт ожидаемый класс `btnCatID` из шаблона, поэтому серверные ID категорий не зашиты в EXE. HTTP-кэш графики проверяется через ETag; цены и права по-прежнему получает и проверяет сервер. Успешная покупка обновляет каталог одним серверным событием. Предпросмотр бумаг и интерьера вписывается в 120×140 без увеличения исходной графики.

При покупке и изменении цены/остатка обновляются данные существующего каталога и текущие ячейки, без сброса категории и номера страницы. Выбранная вещь сохраняется. Полное изменение состава каталога обрабатывается отдельно.

Адаптер обрабатывает штатное завершение ходьбы и точный контур точки до создания старого окна. Каталог запрашивается перед показом магазина; пустое промежуточное окно не открывается.

## Рыбалка

Оригинальная GoldFishing открывается у входа в Севербурге (`mcEntryPoint_81`) или командой `/game goldfishing`. Нажмите круглую кнопку с могоби для начала, затем щёлкайте мышью, чтобы забрасывать крючок. Цель и таймер находятся вверху. Кнопки выхода и помощи и рамка инструкции взяты из оригинального ExternalGamesScreens. Текст инструкции — оригинальный русский GoldFishing из lang.xml; отдельные иллюстрации `GoldFishing_mlGameHelp` пока не найдены. Открытие справки ставит игровой таймер на паузу. Выход или Esc завершает попытку и сохраняет заработанное; после обычного и досрочного завершения показывается оригинальный экран наград `mlGameOverSingle` с очками и монетами. Его кнопка выхода возвращает в исходную комнату. Таблица рекордов пока отключена. F5 отменяет активную попытку и переподключает в ту же комнату.

При естественном и досрочном завершении сервер сохраняет результат и начисляет за каждые 100 очков 1 монету и 1 единицу опыта, максимум по 100 за игру. Это текущая настройка восстановления, исторический курс не подтверждён. Итог показывается на оригинальном экране результата миниигры. Графика встроена в EXE; внешний архив для запуска не требуется.

## Музыка комнат

В клиент встроены оригинальные треки Новограда, Отдыхаево и лабиринта (пока у входа). Звук переключается штатной кнопкой; при переходе предыдущий фон затихает, во время рыбалки приостанавливается. [Привязки и комплектность звука](../docs/room-audio.md). После обновления клиента перезапустите сервер для передачи переменной музыки комнат.
